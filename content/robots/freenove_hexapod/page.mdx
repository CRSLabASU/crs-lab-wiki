The Freenove Big Hexapod is a six-legged walking robot kit driven by a Raspberry Pi. A server program on the Pi controls the legs, camera and sensors, and a client app on a computer or phone drives it over Wi-Fi.

## Software environment

### Installation (on the Raspberry Pi)

Use Raspberry Pi OS with Desktop. All code is Python 3 — running it with Python 2 may cause errors.

```bash
cd
git clone --depth 1 https://github.com/Freenove/Freenove_Big_Hexapod_Robot_Kit_for_Raspberry_Pi.git
cd ~/Freenove_Big_Hexapod_Robot_Kit_for_Raspberry_Pi/Code
sudo python setup.py
```

The setup script installs the required libraries, including `rpi_ws281x` and PyQt5. On a Raspberry Pi 5 it asks which camera port to use (`cam0` or `cam1`).

Increase the I2C speed by adding this line to `/boot/firmware/config.txt`:

```text
i2c_arm_baudrate=400000
```

Then reboot:

```bash
sudo reboot
```

<Callout type="tip">
  Installing the libraries takes a while. Power the Pi from a USB power supply
  during installation; batteries are only needed to drive the servos, LEDs and
  other peripherals.
</Callout>

## How-To

### Start the robot server

On the Raspberry Pi:

```bash
cd ~/Freenove_Big_Hexapod_Robot_Kit_for_Raspberry_Pi/Code/Server
sudo python main.py
```

To run without the server window (for example over SSH), use `sudo python main.py -tn`.

### Connect the client

Run the client on a computer, enter the Pi's IP address and connect. On macOS, run `setup_macos.py` from the `Code` folder first, then start `python3 Main.py` from `Code/Client`. On Windows, run `Client.exe` or install with `setup_windows.py`.

| Control          | Key / input |
| ---------------- | ----------- |
| Move / turn      | W A S D     |
| Video on/off     | V           |
| Relax servos     | R           |
| LED control      | L           |
| Balance mode     | B           |
| Face recognition | F           |
| Ultrasonic       | U           |
| Buzzer           | Y           |
| Head / speed     | Sliders     |

### Calibrate the legs

1. Place the robot on the calibration paper in the position shown in the tutorial
2. Connect the client to the server
3. Click **Calibration**
4. Adjust each of the six feet until they line up with the marks on the paper
5. Click **Save**

<Callout type="warning" title="Calibrate before walking">
  Poor calibration affects how the robot walks. Recalibrate whenever the legs
  are reassembled or movement looks uneven.
</Callout>

## Troubleshooting

### Servo arms installed at the wrong angle

Servos must be set to their installation angle before the servo arms are attached. With the servos connected, run:

```bash
cd ~/Freenove_Big_Hexapod_Robot_Kit_for_Raspberry_Pi/Code/Server
sudo python Servo.py
```

Do not pull on servo wires while assembling.
